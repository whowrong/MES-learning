## 1. 题目目标与业务背景

**目标**：把 items 表里 unit 为 PCS 或 pcs 的记录统一改成「个」。执行成功后提交校验。

**业务背景**：同一个轴承，A 记录单位写「个」，B 记录写「PCS」，C 记录写「pcs」。库存汇总时按单位分组，一个物料拆成三行——报表全乱。数据治理第一条：计量单位字典化。

## 2. 涉及的数据表或服务

- 涉及表：`items`
- 练习库结构：内置练习库共 8 张表（items / bom / employees / equipment / work_orders / work_reports / inventory / sales_orders），合计约 231 行；真实连库时按第 4 节的空间与数据量建议预置同量级数据。

## 3. 需要的账号与权限

## 5. 标准步骤

```sql
UPDATE items SET unit = '个' WHERE unit IN ('PCS','pcs')
```

- 思路提示：UPDATE items SET unit='个' WHERE unit IN ('PCS','pcs')；改之前先跑同条件的 SELECT 确认行数
- 讲解：UPDATE 的职业习惯：先用同条件 SELECT 预览影响行数，确认无误再改。WHERE 里 IN ('PCS','pcs') 大小写都要列——多数库字符串比较默认区分大小写（MySQL 视校对规则而定，SQL Server 默认不区分，PostgreSQL 严格区分），跨库写清洗脚本时宁可多列不可漏列。洗完记得在数据字典里把「个」定为标准单位，堵住录入源头。

判分方式：按状态判定——执行你的 SQL 后重新跑校验 SQL，取状态类字段与期望值比对。

```sql

```

- 期望结果：`[[0]]`
