# MES-learning · 车间操盘手：MES 实施模拟器

一个把「MES 技术实施」岗位知识做成闯关游戏的学习网站：你扮演刚进场的实施顾问，在虚拟工厂里做调研、洗数据、建模配置，一路把项目推上线。面向 MES 技术实施实习生 / 校招生培养，兼顾 MES 运维视角。

## 玩什么

- **章节关卡**（当前 4 章可玩）：调研认知 → 静态数据与脏数据清洗 → 建模与配置 → 执行与报工，每章 = 剧情 + 多种玩法 + 仪表结算 + S/A/B/C 总评分
- **五种玩法**：车间黑话连连看（一句话在说哪个概念）、真假鉴定（题库自动衍生，组合上千种）、场景抉择、限时填空口诀、流程排序
- **术语卡库 + Anki 式间隔复习**：34 张术语卡带知识点映射（K0 数据意识 ~ K6 上线陪产、K7 厂型认知），其中 17 张核心卡配讲解图——BOM 树、工艺路线流动图（工件会沿线跑）、倒冲扣料算式、工单状态机、产出漏斗、在制品水位（带警戒红线）、账实对照、派工板、批次追溯链、节拍时间轴等 16 种可视化，难懂概念直接画给你看；错题自动进复习队列，四档自评调度（10min/4h/1d/3d/7d/16d/35d）
- **面试训练营**：实习 → 校招 → 社招 → 1/2/3 年经验六档难度，五大分类（实施业务/数据/SQL/运维/软素质），单选、多选、判断、简答自评四题型；每题附参考答案 + 加分点，答完出总分与面试官锐评
- **厂型特训营**：离散制造 / 流水线 / 混合型三种厂型，选卡页配形态小图（离散点状流转 / 流水线一线直贯 / 混合两段汇流），各配厂型档案（生产组织、建模重点、调研清单、典型踩坑）与专属场景测验题库
- **运维训练营**（严肃实操，非游戏化）：以 MES 为中心、ERP/WMS 为辅的四大训练域——Linux 服务器实操、Windows 服务器运维（IIS / SQL Server / PowerShell）、云环境运维（安全组 / 迁云割接 / 账单治理）、三系统集成排障（消息队列积压 / 数据库阻塞）。核心是**交互式模拟终端**：读事故工单、真敲命令、按正则判定逐步推进并返回逼真输出；终端文字可选中复制，顶栏「复制全部」一键复制工单上下文 + 完整终端记录（可直接贴给 AI 请教）；`rm -rf /`、`iisreset`、不带 WHERE 的 DELETE 等危险操作会被拦截并讲解真实后果；练完出评级报告 + 标准操作序列（SOP）回放。另配场景决策题与处置流程排序。**真实服务器模式**：登记自己的 Linux 演练机（SSH 密码/私钥，凭据只存服务端、界面脱敏），在真实终端里对它敲命令（危险命令先弹确认）；预置四份部署手册（环境初始化 / MySQL 演练库 / 采集服务 systemd 化 / Prometheus+Grafana 监控），可 SFTP 上传到服务器并按命令序列逐条确认一键部署，也可打包成「部署任务包」复制 / 下载 / webhook 推送给自己的 AI agent 执行
- **数据库实操营**（真实 SQL 执行环境）：内置一套带典型脏数据的 MES 业务练习库（物料 / BOM / 工单 / 报工 / 库存 / 销售订单 / 员工 / 设备八张表，一物两码、单位混乱、状态口径不一、账实不符全埋在里面），四组 16 个实操任务——单表查询与业务口径、多表关联与数据断链、数据清洗实操（真的执行 UPDATE 再校验库状态）、报表与决策支持；每条 SQL 真执行、按结果集自动判分（提交次数越少分越高），讲解全部站在实施顾问视角（口径陷阱、方言差异、LEFT JOIN 找断链）。**SQL 工作台**支持登记连接自己的 MySQL / SQL Server / PostgreSQL 远程库自由执行（真连默认只读保护，危险语句确认拦截，原生报错原样展示）
- **学习打卡**：连续学习天数 streak，通关、复习完成与模拟面试都算打卡
- **移动端适配**：安卓手机可完整游玩（连连看底部概念抽屉等）

## 内容驱动架构

所有题目、剧情、判定反馈都在 `public/content/` 的 JSON 文件里，**加新章节不用改代码**。格式文档与出题红线（题干不漏答案、一题只有一个可辩护答案、唯一锚点表、三句话讲解）见 [`docs/content-format.md`](docs/content-format.md)。

## 技术栈

React 19 + TypeScript + Vite + Tailwind v3 + shadcn/ui；后端 PocketBase（存档/复习调度持久化 + 数据库/SSH 代理路由，经服务端 node 执行器走 mysql2 / pg / mssql / ssh2 / node:sqlite 驱动）；vitest 595 个自动化测试（含 jsdom 渲染级四章全流程、运维训练营与数据库实操营全流程冒烟、关卡/面试题库/厂型内容/运维内容/数据库内容五套红线自动扫描、讲解图注册表一致性校验、模拟终端与 SQL 判定引擎单测）。题库总量 320 题：四章关卡 202 题（连连看 136 + 抉择 45 + 填空 21，另有真假鉴定按局衍生、流程排序 4 套）、面试六档 85 题、厂型三库 33 题；另有运维训练营 48 个训练项目（8 个终端演练 + 32 道场景决策 + 8 套处置流程排序）、数据库实操营 16 个真实执行任务与 4 份部署手册。

```bash
pnpm install
pnpm build   # tsc -b && vite build
npx vitest run
```
